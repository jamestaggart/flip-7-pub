# Security Policy

## Supported scope

This project is a solo-maintained game project. Security fixes are best effort.

## Reporting a vulnerability

Please do not post suspected vulnerabilities in a public issue first.

Open a private disclosure if the platform supports it, or contact the maintainer directly. Include:

- Affected component
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

## Secrets policy

- Never commit `.env` or private keys.
- Use `.env.example` for placeholders only.
- Rotate any credential immediately if exposed.
